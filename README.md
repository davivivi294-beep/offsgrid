# offsgrid

Painel educacional de **cyber security** com ferramentas reais e simulações visuais.

## ⚠️ Aviso

Projeto **100% educacional**. Ferramentas reais operam apenas na sua própria máquina/rede. Simulações não acessam nenhum dispositivo.

## 🚀 Instalação

```bash
git clone https://github.com/SEU_USUARIO/offsgrid.git
cd offsgrid
pip install -r requirements.txt
pip install -e .
offsgrid
